Machine vision · system control surface

        

          

            
↗ Screenshot → analyze

            
Capture the current screen and ask the active LLM to describe what's on it, transcribe text, or suggest next action. Uses your configured cloud key (Anthropic/OpenAI/OpenRouter).

            
          

          

            
↗ OCR on file

            
Drop an image file and extract text via the local pytesseract bridge in backend/agents/vision_agent.py. Works offline.

            
          

          

            
↗ Selection → speak

            
Bind a global shortcut: capture screen region → OCR → speak via TTS. Free screen-reader-style accessibility helper. Coming with W203.

            
          

          

            
↗ Agent-driven actions

            
Future: let an agent describe what it sees, propose a click, ask HIL approval, perform via macOS Accessibility API. Receipts-logged.
