FAQ

The questions actually asked.

Is TARS just another wrapper around Claude / GPT?
No. TARS is a local-first cockpit: voice STT/TTS, persistent memory (SQLite + sqlite-vec), 7 domain packs with their own awareness/actions/HIL gates, hash-chained signed receipts, background agents via launchd/systemd, and a $MEEET marketplace. You bring your own LLM (Anthropic, OpenAI, OpenRouter, Ollama). The intelligence is provider-agnostic; the cockpit is the product.
How is it different from Cursor?
Cursor is the best-in-class IDE for code. TARS is for everything else: wealth, health, family, product, brand, entrepreneurship, civic. Voice-first instead of chat-first. Multi-domain instead of code-only. Signed receipts instead of cloud trust. Both can coexist — many users run Cursor for code and TARS for everything else.
What about my data?
By default TARS runs entirely on your Mac — SQLite database, encrypted at rest. No telemetry, no cloud upload unless you opt in. Optional Pro tier offers cross-device sync via meeet.world with client-side encryption (we never see plaintext). On-prem Docker stack available for businesses with strict data residency.
What are "receipts on Solana"?
Every agent action is signed Ed25519 with your key, hash-chained into a local ledger, and (on Pro+) periodically Merkle-rooted into a Solana memo transaction. Anyone can independently verify what your agents did, when, and to which data. Audit-grade. Cheaper and faster than Ethereum logs — typical anchor is <0.001 SOL.
Does it work offline?
Yes — if you use a local LLM via Ollama or LM Studio. Voice cockpit, memory, domain packs, codebase indexer, receipts ledger all work offline. Cloud features (Solana anchoring, cross-device sync, ElevenLabs TTS) require network. The whole point is: your cockpit, your keys, your laws.
Mac only, or Windows / Linux too?
v10 ships signed for macOS arm64 + x64, with Windows .exe and Linux .deb / .AppImage builds in the same release. Voice cockpit and background daemon work on all three. macOS is the primary target for now; Windows and Linux are tested but may have rougher edges. See latest release →
What's $MEEET and do I need it?
$MEEET is the agent economy token on Solana — used for T2T marketplace transactions (one agent paying another for work). You do not need it to use TARS. The Free + Pro tiers don't require any token. $MEEET only comes into play if you opt into the marketplace as a buyer or skill-builder.
How do I trust an unsigned binary?
v10.0.0-rc.1 release candidates are unsigned and require xattr -cr /Applications/TARS.app to bypass Gatekeeper. v10 GA (this week) ships signed + notarized via Apple Developer ID. We will never ask you for sudo. Install script is auditable: curl -sSL https://tars.meeet.world/install.sh | less.
