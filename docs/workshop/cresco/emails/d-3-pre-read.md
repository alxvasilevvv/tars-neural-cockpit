## The pre-read

1. **What is a Strategy IR?** — `docs/contracts/STRATEGY_IR.md`.
   The intermediate representation TARS uses to describe a
   trading strategy in a form that a backtester, a risk policy,
   and an audit log can all consume. Read for shape, not detail.

2. **Risk policy patterns we'll cover** —
   `docs/RISK_POLICY_PATTERNS.md`. Five patterns we'll work
   through on Day 2 morning: hard exposure caps, drawdown
   throttles, vol-targeted sizing, kill-switch hooks, and HIL
   (human-in-the-loop) gates. The doc is a primer; we'll
   configure each pattern in the workshop.

3. **Backtest interpretation: Sharpe vs Sortino vs PF** —
   `docs/METRICS_PRIMER.md`. A short comparison of the three
   ratios we report by default, when each one lies, and what to
   look at alongside them. If you already use these daily, skim
   the failure-mode section at the end.
