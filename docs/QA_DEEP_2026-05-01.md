### 🚨 P0-1. TARS install полностью сломан
- **Где:** `https://tars.meeet.world/api/product/downloads` отдаёт JSON с тремя artifact-URL'ами вида `https://meeet.world/dl/TARS-8.4.0-arm64.dmg`

### P1-9. /assets/* без Cache-Control header
- HEAD на `/assets/index-CcfNpiwM.js` → `Cache-Control: None`, но есть ETag
- Cloudflare кэширует по ETag (norm), но без явного `Cache-Control: public, max-age=31536000, immutable` это subooptimal — браузеры пересваливают на revalidation
- На tars.meeet.world уже хорошо: `public, max-age=60, s-maxage=300, stale-while-revalidate=86400`
- **Fix:** скопировать tars-настройку в meeet.world Cloudflare config

### P1-10. API base /api/v1 не существует
