## 6. Critical-path summary

The single longest path through the chart is:

```
v10.0 GA (T+0)
   |
   -> SOC2 auditor engagement (90 days)
   |
   -> v10.4 Enterprise tag (T+92d)
   |
   -> v10.5 Marketplace tag (T+122d)
   |
   -> v11.0 Agentic OS tag (T+183d)
```

The two items on the critical path that we control least:

1. **SOC2 auditor turnaround** (90 days minimum, external).
2. **Brother's $MEEET payout pipeline for v10.5** (external — must
   support batched weekly Solana payouts).

Mitigation: start both engagements *the day v10.0 ships GA*. If
brother can ship batched payouts earlier, we pull v10.5 forward.
