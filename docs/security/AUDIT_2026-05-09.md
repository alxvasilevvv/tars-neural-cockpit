### 3. Public endpoints lacking auth

The audit dossier says "single-tenant — desktop is single-user", and
the default sidecar bind is `127.0.0.1:8765` (`serve.py:27`), so
endpoints rely on loopback isolation. Findings cover the case where the
operator (or `core-bridge` proxy) exposes the sidecar on a public
interface.

| Router | Auth model | Severity | Action |
| --- | --- | --- | --- |
| `/api/wallet/{wallet_id}/sign` (arbitrary message) | None ⟶ **fixed** to call `policy_gate.require_confirm` (matches all other `sign_*` endpoints) | **HIGH (fixed)** | Code patch in `web_extras/routers/wallet.py` |
| `/api/wallet/{wallet_id}/sign_solana_transfer`, `/sign_ton_transfer`, `/sign_evm_tx`, `/{id}` `DELETE` | Opt-in HMAC confirm gate (`TARS_REQUIRE_OPERATOR_CONFIRM=1`) | OK (single-user desktop default) | Operator must set `TARS_REQUIRE_OPERATOR_CONFIRM=1` for any non-loopback bind — see `OPERATOR_ACTIONS.md` |
| `/api/wallet/import`, `/api/wallet` `POST/GET/DELETE` (non-sign), `/policy/status`, `/{id}/confirm`, `/solana/blockhash`, `/evm/{addr}/nonce` | None | MEDIUM | Acceptable on loopback; documented operator gate for remote |
| `/api/agents/route` | None | **HIGH (fixed)** | Added rate-limit bucket `agents.route` (15/min sustained, 30 burst) |
| `/api/agents`, `/api/agents/{id}/tasks`, `/api/tasks/{id}/run`, etc. | None | MEDIUM | Single-user desktop OK; flag for hardening when shared host |
| `/api/chat/threads/{id}/messages` | `require_cloud_budget` only | OK | Already has `chat.post_message` rate-limit bucket + budget gate |
| `/api/memory/*` | None | MEDIUM | Single-user OK |
| `/api/clone/profile`, `/api/clone/record` | None | LOW | Read/write style profile; not destructive |
| `/api/clone/draft` | None | **HIGH (fixed)** | Added rate-limit bucket `clone.draft` (10/min sustained, 20 burst) — calls cloud LLM |
| `/api/voice/transcribe` | None | **HIGH (fixed)** | Added rate-limit bucket `voice.transcribe` (20/min sustained, 30 burst) — Whisper bill protection |
| `/api/voice/speak` | `require_cloud_budget` + rate-limit `voice.speak` | OK | |
| `/api/github/*` | `_require_token()` resolves from secrets store / env; returns 503 when not configured | OK | |
| `/api/oauth/smtp/start`, `/exchange` | Stateless — PKCE `code_verifier` + HMAC-signed `state`; no session table | OK | |

### 6. Rate limiting

Pre-audit, the `expensive_routes_rate_limit` middleware covered:
`chat.post_message`, `planner.run`, `voice.speak`, `council.deliberate`.

**Gap:** the cloud-billed endpoints below were unprotected → potential
runaway bill if exposed.

| Endpoint | Pre-audit | Post-audit (this commit) |
| --- | --- | --- |
| `POST /api/voice/transcribe` (Whisper) | none | **bucket `voice.transcribe`** — 30 burst / 20 per minute |
| `POST /api/agents/route` (LLM intent classifier) | none | **bucket `agents.route`** — 30 burst / 15 per minute |
| `POST /api/clone/draft` (LLM draft) | none | **bucket `clone.draft`** — 20 burst / 10 per minute |

All three buckets are env-overridable with `TARS_RATE_LIMIT_<BUCKET>_BURST`
/ `_PER_MINUTE` (matches the existing four-bucket convention).

## Fixes applied in this commit

1. **`web_extras/middleware/expensive_routes_rate_limit.py`** — three
   new `ExpensiveRoute` entries: `voice.transcribe`, `agents.route`,
   `clone.draft`. Closes the only known cloud-billed surfaces that were
   bypassing the per-IP token-bucket throttle.
2. **`web_extras/routers/wallet.py`** — `POST /api/wallet/{wallet_id}/sign`
   now calls `policy_gate.require_confirm(action="wallet.sign_message")`,
   matching the chain-specific transfer endpoints. No-op when
   `TARS_REQUIRE_OPERATOR_CONFIRM` is off (default), so existing tests
   and the desktop dev flow keep working.
3. **`docs/security/AUDIT_2026-05-09.md`** (this file).
4. **`docs/security/OPERATOR_ACTIONS.md`** — checklist of must-do
   operator tasks (rotate `cf-operator.env`, flip
   `TARS_REQUIRE_OPERATOR_CONFIRM=1` on remote binds, etc.).
5. **`docs/security/WHAT_NEEDS_HARDENING.md`** — tracker for MEDIUM /
   LOW items deferred past launch.
