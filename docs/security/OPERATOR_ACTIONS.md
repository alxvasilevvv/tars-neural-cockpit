# Operator Actions — Pre / Post Launch Security Checklist

These tasks live OUTSIDE the codebase — TARS cannot do them on the
operator's behalf. Cross off in order before / right after launch.

Generated by Wave 79 audit (`docs/security/AUDIT_2026-05-09.md`).

## Before public launch (CRITICAL — do today)

- [ ] **Rotate `CLOUDFLARE_API_TOKEN`** in `cf-operator.env`.
      The existing token has been live since the Cloudflare Pages
      provisioning ran. Rotate it now so the recorded value never
      survives a hypothetical future leak. Steps:
      1. Cloudflare → Account → Cloudflare Pages → **Edit**
      2. Generate a fresh `cfat_…` token
      3. Paste into `cf-operator.env` (one line, no whitespace)
      4. `make ops-cf-pages-token` to push to GitHub Actions secret
      5. Revoke the old token in Cloudflare

- [ ] **Confirm `cf-operator.env` is gitignored.**
      `git check-ignore -v cf-operator.env` should print
      `.gitignore:18:cf-operator.env`. If not — DO NOT COMMIT — fix
      `.gitignore` first.

- [ ] **Sidecar bind is loopback** (`HOST=127.0.0.1`, the default).
      Verify: `lsof -nP -iTCP:8765 | grep LISTEN` should show
      `localhost`. **Never** set `HOST=0.0.0.0` on a multi-tenant
      machine without also doing the next two items.

- [ ] **If the sidecar is exposed beyond loopback** (e.g. via the
      meeet.world `core-bridge` proxy):
      - [ ] Set `TARS_REQUIRE_OPERATOR_CONFIRM=1` so destructive wallet
            endpoints (`/sign`, `/sign_*_transfer`, `/sign_evm_tx`,
            `DELETE /{id}`) require an HMAC confirm token.
      - [ ] Set `TARS_CONFIRM_KEY=<32-bytes-base64>` to a stable
            secret (otherwise the in-memory key is regenerated on each
            sidecar restart, invalidating already-issued confirm
            tokens).
      - [ ] Set `BRIDGE_SHARED_SECRET=<random>` and mirror it on the
            meeet.world Supabase project (`zujrmifaabkletgnpoyw`) +
            GitHub Actions repo secrets (see `docs/SYNC.md §7`).
      - [ ] Tighten `TARS_CORS_ORIGINS` to the exact public origins.

- [ ] **Verify `TARS_RATE_LIMIT_EXPENSIVE` is NOT set to `off`** in
      production. Default is on; only set `off` in tests / single-user
      dev where you accept that a runaway client can spend the entire
      cloud budget.

## Within 7 days of launch (HIGH)

- [ ] **Set `QA_INGEST_TOKEN`** if `/api/qa/report` is reachable from
      anywhere except localhost. Otherwise anyone can `POST` a fake QA
      report and overwrite `qa-suite/.reports/findings.json`.

- [ ] **Decide on `/api/qa/report` GET visibility.** It currently
      surfaces probe names + summary counters + `base_url`. On a
      remote bind, gate it behind the same `QA_INGEST_TOKEN` (or move
      it inside an admin namespace).

- [ ] **Consider tightening Cloudflare Pages CSP** in
      `experiments/neural-showcase-v3/public/_headers`. Current header
      only sets `frame-ancestors`. Adding `default-src 'self';
      script-src 'self'; style-src 'self' 'unsafe-inline'; img-src
      'self' data:; connect-src 'self' https://meeet.world` would
      block any future inline-script regression. Test the marketing
      build before shipping (Vite occasionally inlines tiny scripts).

## Recurring (every 90 days)

- [ ] Rotate `CLOUDFLARE_API_TOKEN` in `cf-operator.env`.
- [ ] Rotate `BRIDGE_SHARED_SECRET` (coordinate with meeet.world /
      brother).
- [ ] Rotate `MEEET_API_KEY` / `TARS_INGEST_API_KEY` in repo `.env`
      and the matching Supabase secret.
- [ ] Re-run the audit:
      `python -m scripts.qa_agent --json && rg -nE 'cfat_|ghp_|sk_live'
      $(git ls-files)` → confirm nothing new.

## After any contributor leaves the project

- [ ] Rotate every shared secret listed above (`CLOUDFLARE_API_TOKEN`,
      `BRIDGE_SHARED_SECRET`, `MEEET_API_KEY`, `TARS_INGEST_API_KEY`,
      `TARS_CONFIRM_KEY`).
- [ ] Revoke the contributor's GitHub repo / Cloudflare team access.
- [ ] Audit committed secrets one more time
      (`grep -rE 'cfat_|ghp_|sk_live|sk_test|xoxb-' --untracked-files`).
