## 1. Style direction (skill: Real-Time Monitoring + HUD/Sci-Fi FUI + Dark Mode OLED)

The skill's master pick is **Real-Time Monitoring**. Supplemental
domain searches add **HUD / Sci-Fi FUI** (`--domain style "real-time
monitoring HUD operator dark"`) and **Dark Mode (OLED)** for the
palette/contrast frame. Apply in this order of weight:

1. **Real-Time Monitoring** (primary)
   - Live data updates, status indicators, alert notifications,
     streaming chart aesthetics.
   - Effects: real-time chart animations, alert pulse / glow, status
     indicator blink, smooth data stream updates.
   - Performance ⚡ Good · Accessibility ✓ WCAG AA.
2. **HUD / Sci-Fi FUI** (technical detail layer)
   - 1px hairlines, decorative tech markers (corner brackets, ticker
     ribbons), monospaced labels.
   - Glow only on the single primary accent, sparingly:
     `text-shadow: 0 0 12px var(--color-accent-soft)`,
     `box-shadow: 0 0 24px var(--color-hud-soft)`.
3. **Dark Mode (OLED)** (palette frame)
   - Background near-black; text contrast ≥ 7:1.
   - No `#FFFFFF` background anywhere.

## 2. Pattern (skill: Portfolio Grid → adapted)

Skill's auto-pick was "Portfolio Grid", which fits the showcase landing
but not the cockpit. We adapt to **TARS Cockpit Hero + Live Rail**:

1. Hero — eyebrow + massive split title + 3D core scene + dual CTA.
2. Live Rail — fixed-width awareness streams strip with tick markers
   and a live integrity number.
3. Domain Packs — 4-up grid, monolithic cards, single accent line on
   the left edge per pack.
4. How It Works — 3 numbered steps, oversized numerals, terse copy.
5. Cockpit footer — single deep-link to the operator surface.

CTA placement: above the fold (`Open Cockpit` + `Explore Domains`).
Secondary CTA repeats in the footer (`Open cockpit`).

## 5. Layout (skill spacing variables)

- Container max-width: `1280px`.
- Side padding: `clamp(16px, 4vw, 56px)` (matches skill `--space-md`
  through `--space-2xl`).
- Section vertical: `pt-[140px] pb-[140px]` desktop, `100px` on
  mobile.
- Z-index scale: `10 / 20 / 30 / 50`. Never `9999`.
- Floating navbar: `top-4 left-4 right-4`, never `top-0`.

## 6. Effects (skill: Real-Time Monitoring + HUD)

- **Glow**: only on `--color-accent` (gold) and on the primary CTA
  hover. `text-shadow: 0 0 14px var(--color-accent-soft)`.
- **HUD lines**: 1px, cyan `--color-hud`, opacity 0.32 base, animated
  with `pulseSoft 3.4s`.
- **Hover transitions**: 200ms ease-out, color/opacity only.
  `translateY(-2px)` max — no `scale` shifts on cards.
- **Bloom in WebGL**: intensity ≤ 0.85, threshold ≥ 0.18,
  `kernelSize: MEDIUM`. The 3D scene is a background sculpture, not
  the focal point.
- **Status pulse** (skill effect: alert pulse/glow): 1.6s ease-in-out,
  used only on `LIVE` dots and stream markers.
- **Streaming-data updates**: smooth `animate(value, target)` from
  framer-motion (≥600ms), never instant jumps for numbers.

## 7. Motion (skill UX rules)

- Animate **1–2 key elements per view max** (skill UX result: Excessive
  Motion → Severity High).
- Use **ease-out** for entering, **ease-in** for exiting (Linear is
  forbidden for UI).
- All operations >300ms must show a spinner/skeleton (Loading
  Indicators rule).
- Forms: Loading → Success/Error sequence; never a silent click.
- **Always** wrap motion in `prefers-reduced-motion: reduce` opt-out.

## 8. Pre-Delivery Checklist (verbatim from skill)

- [ ] No emojis used as icons (use SVG instead).
- [ ] All icons from a single set (Heroicons / Lucide).
- [ ] `cursor-pointer` on all clickable elements.
- [ ] Hover transitions 150–300ms.
- [ ] Text contrast 4.5:1 minimum (we target 7:1).
- [ ] Focus states visible for keyboard navigation.
- [ ] `prefers-reduced-motion` respected.
- [ ] Responsive at 375 / 768 / 1024 / 1440.
- [ ] No content hidden behind fixed navbars.
- [ ] No horizontal scroll on mobile.
